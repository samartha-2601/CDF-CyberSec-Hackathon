
# Hackathon Kickoff Presentation

This directory contains the kickoff and
orientation materials for the CDF CyberSec
Hackathon: Intelligent Code Security Challenge.

## Presentation

The orientation presentation will cover:

- Hackathon introduction
- Challenge overview
- Find, Fix, Fortify requirements
- Sample application walkthrough
- Technical rules
- Expected deliverables
- Evaluation criteria
- Two-day schedule
- Submission instructions
- Questions and support

The final PowerPoint presentation will be added
before the hackathon kickoff.

For complete challenge details, refer to the
main repository README and the documents
in the `docs/` directory.
